Snake Game (Python + PyGame)

#Description

        Classic Snake game developed in Python using PyGame. Improved personal version of a university group project. Focuses on logic, data structures, and event handling.

#Features

        Multiple board sizes (small, medium, large).
        
        Customizable number of apples.
        
        Poisoned apples that reduce score if eaten.
        
        Collision detection with walls and self.
        
        Tracks personal record and total games played.

#Controls

        Move: W / Arrow Up, S / Arrow Down, A / Arrow Left, D / Arrow Right
        
        Select menu options: Enter + arrow keys

#Installation

        Install Python 3.x
        
        Install PyGame:
        
        pip install pygame
        

#Run the game:

        python main.py
